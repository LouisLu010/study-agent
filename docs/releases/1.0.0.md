# 格物 1.0

格物是一个在 iPhone 和 iPad 上用大模型学习的 App，适合学数学、物理、化学这类要看公式、画图、做题的科目。名字取自"格物致知"。

这是第一个正式版。它是免费、开源的个人项目，没有上架 App Store，安装要多花十几分钟，下面会一步步说明。

## 它能做什么

- **会画图的回答**。问"y = x² − 2ax + 1 的图像怎么随 a 变化"，回答里会有一张坐标图，拖动 a 的滑块，曲线跟着动，零点和最小值自动标出来。几何图里的点可以拖，长度和角度跟着变。
- **能动手的模拟**。单摆、弹簧振子、碰撞、带电粒子在磁场里的运动、电路、化学平衡等，可以改参数、播放、拖时间轴。
- **小测验和错题本**。回答里可以出选择题和填空题，答完马上看到对错和解析。答错的题自动进错题本，隔 1、3、7、14、30 天再让你做一次，答对就往后排，直到掌握。
- **换一种讲法**。可以选"循序渐进"（每一步讲清为什么）、"启发式"（一步步提问，引导你自己想出来）、"考前速记"（只给要点和易错点）、"严格批改"（发上自己的解答，逐步挑错并打分）。回答下面还有"讲简单点""换个思路""出道练习题"，点一下就行。
- **拍题、传 PDF、手写**。拍下练习册上的题，或者选 PDF 里的几页，或者用 Apple Pencil 写下来直接问。
- **汇编真题**。一句话说要什么题，例如"近 3 年高考有机大题"，格物会联网找到试卷，从网页上取下题目原文和原图，排成一份 PDF。题目不由 AI 改写。

## 开始之前要准备什么

1. **一台 iPhone 或 iPad**，系统是 iOS / iPadOS 18 或更新。
2. **一台电脑**（Windows 或 Mac），用来把 App 装到手机上。
3. **一个大模型服务商的 API Key**。

**API Key 是什么？** 格物本身不提供 AI，它直接连你选的大模型服务商，就像用你自己的账号去调用。API Key 是服务商发给你的一串密码，费用由服务商按你实际的用量收取，格物不收任何钱。

如果你还没有，推荐先用 **DeepSeek**：在 [platform.deepseek.com](https://platform.deepseek.com/api_keys) 注册、充值少量金额，创建一个 API Key 复制下来。格物也支持 OpenAI、Anthropic（Claude）、Google Gemini、OpenRouter，以及通义千问、Kimi、硅基流动等兼容 OpenAI 接口的服务商。

## 安装

因为没有上架 App Store，需要用自己的 Apple ID 给安装包签名后装到设备上。免费的 Apple ID 就可以。

1. 下载本页底部的 `StudyAgent-v1.0.0-unsigned.ipa`。
2. 在电脑上安装 [Sideloadly](https://sideloadly.io/)（Windows 上还要装 iTunes，Sideloadly 会提示），用数据线连上 iPhone 或 iPad。
3. 打开 Sideloadly，把下载的 `.ipa` 拖进去，填上你的 Apple ID，点 Start。第一次可能要在手机上点"信任此电脑"。
4. 装好后，在手机的"设置 → 通用 → VPN 与设备管理"里找到你的 Apple ID，点"信任"。
5. 如果打开时提示要开启开发者模式：到"设置 → 隐私与安全性 → 开发者模式"打开，手机会重启一次。

**要知道的限制**：用免费 Apple ID 签名的 App 7 天后会打不开，到时候用 Sideloadly 再装一次同一个文件就行，**里面的会话和错题都还在**。免费 Apple ID 最多同时装 3 个这样的 App。

## 第一次打开

格物会带你走几步：选服务商、粘贴 API Key（格物会试着连一下，确认 Key 能用）、选一个模型、选你的年级和喜欢的讲解方式，可以打开每天的复习提醒。之后就可以直接提问了。每一步都可以以后在设置里改。

不知道问什么？可以试试：
- "画出 y = sin x 和 y = cos x 的图像，比较它们"
- "单摆的摆长变长，周期怎么变？给我一个能调参数的模拟"
- "出 5 道等比数列的选择题"

## 隐私和费用

- 你的 API Key 只存在这台设备的钥匙串里。格物直接连服务商，**中间没有任何服务器**，作者看不到你的任何内容。
- 会话、错题、收藏和汇编都只存在这台设备上。目前不会同步到 iCloud，换设备或删掉 App 会丢失，重要的内容可以导出。
- 每条回答下面显示这次用了多少 token、大约多少钱。这是按服务商官网价格算的估算值，以服务商的账单为准。汇编一份真题会搜索很多次网页，比普通提问贵一些，开始前会显示大约需要的时间和费用。

## 目前还不支持

- 只有中文界面。
- 不能在多台设备之间同步。
- 不能在 Mac 上用。
- 组件只能从内置的几种里选，AI 不能自己写新的交互内容。

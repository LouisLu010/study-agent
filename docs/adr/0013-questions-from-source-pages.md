# 汇编的原题从出处网页里取，不让模型抄写

服务端联网搜索只把网页文字交给模型，而题库网站把公式、化学式和结构图都做成了图片，模型看到的题干缺字、合成路线整段为空（A0 第一次试验：5 道有机大题里约 35 个结构，模型一个也没看到）。所以汇编改成两步：模型联网找到原题所在的网页（优先"每题一个页面"的题目详情页），给出题干开头和最后一问开头的几个字；App 自己下载这些网页，按这几个字在网页里定位这道题，按顺序取出文字、公式和图片，图片保存在 App 里，PDF 也用原图。网站附带的答案和解析一起取下来，标为"网站解析"。第二次试验 5 道题有 4 道拿到了完整原题和原图（高途、21 世纪教育网组卷），海淀一模那道只有纯文字的资料页，标为"有图未能获取"。

代价是依赖网站的页面结构：学科网、51 教习会拒绝程序访问，公众号和小红书拿不到正文；网站改版后定位可能失效。这些图片只保存在用户自己的设备上，导出的 PDF 里不放链接。

## Considered Options

- 模型把结构式写成 SMILES，App 用 SmilesDrawer 画：模型根本没看到结构，只能猜，试验里有重复和明显错误的结构。
- 用户自己导入试卷 PDF 或照片，App 按位置裁题：最可靠，但要用户先找到试卷，失去了"一句话汇编"的意义。以后可以作为补充。

# 模拟只用 App 内置的几种，不让模型写代码

模拟（运动和化学过程的动画）沿用 ADR-0006 的做法：新增一种组件 `simulation`，模型只写"哪种模拟"和参数，由 App 在 WebView 里用 Canvas 画动画。之所以不让模型写代码放进沙盒，是因为用真实模型测试时，grok、minimax 连写组件 JSON 都经常出错，写可运行的动画代码只会更不稳定；而且严格的沙盒（禁止联网、隔离来源、限制运行时间和计时器）本身就是一项不小的工作。代价是只能做内置的那几种模拟，新增一种就要写一次代码。

## Considered Options

- 模型写 HTML/JS 小程序放进沙盒运行：什么都能做，但效果取决于模型的写代码能力，需要严格的沙盒。
- 内置模拟为主，表达不了时允许模型写代码：两套机制都要维护，等内置模拟不够用时再考虑。

# 坐标图由模型给出结构化描述、在设备上绘制

ChatGPT 是让模型写 Python、在服务器上执行后返回静态图片。我们没有后端（见 ADR-0001），所以改为让模型在回答里输出一个 ```` ```graph ```` 代码块，里面是一段描述坐标图的 JSON（函数、点、线段、坐标范围）。App 在消息的 WebView 里（见 ADR-0003）用 JSXGraph 把它画成可缩放、可拖动的交互图。JSON 不合法时，就把代码块原样显示出来。代价是只能画我们支持的图形类型，第一版只支持二维直角坐标系。

## Considered Options

- 服务器执行代码出图：需要后端和代码沙箱，图是静态的。
- 嵌入 Desmos 或 GeoGebra：功能最强，但依赖网络，还要遵守第三方授权条款。
- 用工具调用（function calling）代替代码块：结构更严格，但三种协议的写法各不相同，部分 OpenAI 兼容的模型不支持。

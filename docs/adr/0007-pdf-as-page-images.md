# PDF 在设备上转成页面图片再发送

用户发送 PDF 时，App 用 PDFKit 把选中的页面渲染成 JPEG，作为普通图片附件发给模型，不提取文字层，也不上传原始 PDF。这样三种协议、所有支持图片的模型都能用，扫描件和手写试卷也能看懂。代价是比纯文字费 token，而且模型必须支持图片输入。每条消息最多 10 个附件，PDF 页面和照片一起计数。

## Considered Options

- 提取 PDF 的文字层：便宜，不支持图片的模型也能用，但扫描件没有文字层，公式和图形会丢失。
- 直接上传原始 PDF：只有 Claude 和 Gemini 原生支持，OpenAI 兼容的中转服务基本不支持。

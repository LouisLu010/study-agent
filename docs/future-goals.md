1. 全局学习助手。首版已实现，随 1.2.0 开发版验证：跨会话、错题、知识卡和汇编查找已有内容，分析一组错题，用已有材料组织专题学习。回答附可打开的本地原记录，保留会话和用量，按需读取内容。范围与实现见 README 的“第十一版范围”。

</spec-entry>

<spec-entry category="arch" keywords="未来目标,学习画布" date="2026-11-28" source="README.md:468">

2. 学习画布。首版已实现：原题、可交互的坐标图、知识卡、会话消息和可继续编辑的手写保存为专题副本；支持自由摆放、缩放、框选和多选提问。见 README“第十二版范围”。

</spec-entry>

<spec-entry category="arch" keywords="未来目标,多解对照" date="2026-11-28" source="README.md:468">

4. 多种解法并排对照。首版已实现：同题的两至三种解法按共同目标并排，显示条件、关键转折与可省步骤；支持自己的解法并核对原文引用，保存材料与分析结果。见 README“第十三版范围”。

</spec-entry>

<spec-entry category="arch" keywords="未来目标,知识缺口,关系图" date="2026-11-28" source="README.md:468">

5. 知识缺口定位。首版已实现：沿同科目前置关联生成少量检查题，保存作答，建议逐条核对作答证据并可返回知识卡；未作答标为证据不足。见 README“第十四版范围”。

</spec-entry>

<spec-entry category="arch" keywords="未来目标,题目条件,变式" date="2026-11-28" source="README.md:468">

6. 题目条件探索。首版已实现：按唯一原文片段替换或去掉条件，保存原题和独立变式，分析推导变化并尝试反例；可核对自己的原解法。见 README“第十五版范围”。

</spec-entry>
